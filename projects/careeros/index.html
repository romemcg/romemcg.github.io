CareerOS

A local desktop app for job search that builds tailored CVs from verified facts only, so it cannot invent claims.

LLM APITauri 2ReactTypeScriptSQLiteRust

The problem

Tailoring a CV for every role by hand is slow, and AI tools are happy to invent metrics. A CV that cannot survive a background check is worse than none.

Who it is for

Me first. Anyone who needs to tailor applications without fabricating.

My role

Product owner, designer and builder.

Approach

  • Import a master CV, verify each fact, then match facts against a job description.
  • Generate a tailored CV from verified facts in an exact template.
  • Everything runs locally on the Mac. The API key lives in the system keychain, never in the interface.

Product decisions

  • The database itself enforces that only verified facts can appear on a CV.
  • The AI only selects and orders pre verified bullets. It never writes new claims.
  • Local first, because a job search holds private data.

Results

  • In active development.

What is next

  • Finish the paste a job description, review, approve, generate flow
  • Use it on real applications and measure what helps
